# Aragog 

**Aragog** is an open-source Python package for computing one-dimensional interior dynamics of rocky planets, including partially molten and fully solid regimes. It is the interior evolution model of the PROTEUS exoplanet modelling framework. 

!!! note
    This documentation describes the version integrated into the [PROTEUS framework](https://proteus-framework.org/PROTEUS). For documentation of the original project, see [ExPlanetology](https://aragog.readthedocs.io).

If you plan to contribute to Aragog, please read our [Code of Conduct](Community/CODE_OF_CONDUCT.md). If you are running into problems, please do not hesitate to raise an [issue](https://github.com/FormingWorlds/aragog/issues).
