# Aragog Documentation

Welcome to the documentation of *aragog*. 

**Note**: this documentation describes the version of aragog as used within the [PROTEUS framework](https://proteus-framework.org/PROTEUS). If you'd like to go to the documentation of the original version, please follow this link: [aragog ExPlanetology](https://aragog.readthedocs.io). 

Aragog is a Python package that computes the 1-D interior dynamics of rocky planets with molten or solid interiors. It is released under [The GNU General Public License v3.0 or later](https://www.gnu.org/licenses/gpl-3.0.en.html). 

**Author:** Dan J. Bower  
**Institute of Geochemistry and Petrology**  
**ETH Zurich, Switzerland**

###  Source code

*Aragog* is available at [Forming Worlds](https://github.com/FormingWorlds/aragog). 

*Aragog* was originally forked from: [Explanetology]((https://github.com/Explanetology/aragog).
