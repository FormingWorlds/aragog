## Equation-of-state tables

The pressure-entropy lookup tables that Aragog reads at startup are produced by the PALEOS code, currently in preprint:

- **Attia, M., Lichtenberg, T., Werlen, A., Bonati, I., Bower, D., et al. (2026).** PALEOS: A planetary entropy and structure model. *Manuscript in preparation.*

For the PALEOS file format and how the tables are wired into the run directory, see [Reference: data](data.md).

Additionally, Aragog is part of all publications of the PROTEUS Framework, which can be found [here](https://scixplorer.org/public-libraries/EVAJ1UgWTCy2Z7TRoSmjtQ).
