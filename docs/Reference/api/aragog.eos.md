# `aragog.eos`

The `aragog.eos` package provides the pressure-entropy equation of state used by the solver. The production path is a single phase-aware evaluator backed by SPIDER-format $(P, S)$ tables; there is no abstract evaluator protocol or single/mixed/composite hierarchy.

| Name | Role |
|------|------|
| `EntropyEOS` | P-S table loader and bilinear interpolator. Provides `temperature(P, S)`, `density(P, S)`, `melt_fraction(P, S)`, `solidus_entropy(P)`, `liquidus_entropy(P)`, `latent_heat(P)`, `solidus_entropy_dP(P)`, `liquidus_entropy_dP(P)`. |
| `EntropyPhaseEvaluator` | Wraps `EntropyEOS` with the SPIDER-parity two-stage phase blend, viscosity tanh transition, gravitational-separation velocity, and the per-cell property cache. |
| `mobility_function` | Three-regime permeability over porosity $F(\phi)$ [m²] that the gravitational-separation velocity uses, from the porosity and the grain size. |
| `consistency.residuals` | How far the P-S tables of one phase are from $(\partial T/\partial S)_P = T/c_p$, from the tabulated $(\partial T/\partial P)_S$, from $(\partial T/\partial P)_S = -(1/\rho)(\partial \ln\rho/\partial S)_P$ and from $(\partial T/\partial P)_S = \alpha T/(\rho c_p)$, as relative numbers. Slopes come from central differences on the table grid; a step that meets a missing cell gives none. |
| `consistency.check` | Tests each cell of those tables against a Richardson bound: the round-off floor of the stored values, at 9 significant digits at best, plus twice the $h^4$ term measured at the cell. The floor also covers the rounding of the stored $P$ and $S$ coordinates, taken as the departure of each coordinate from the uniform or geometric fit of its axis ($\epsilon |x|$ for an irregular axis). An axis is regular when it lies within $10^{-6}$ steps plus $\epsilon |x|$ of a uniform fit, or within the same relative limit of a geometric fit; $\epsilon$ is the precision of the stored values and of the coordinates. One coordinate beyond that limit moves the whole axis to $\epsilon |x|$. The Wolf & Bower 2018 P-S tables (the legacy copy in `FWL_DATA`, read at run time, not shipped with aragog) take $\epsilon |x|$: their $P$ coordinates lie about $10^{-5}$ of a step off a uniform grid and their $S$ axis is not uniform, so their floor is larger and fewer of their cells fail than with a regular axis. Their coordinates are stored to 18 digits, so for them the term is an upper bound, not the rounding of the file; on such an irregular axis a $10^{-6}$ fault can be missed two cells away. A central difference on an uneven grid also carries a first-order error that the floor does not cover: an exact table on an $S$ axis that alternates by $10^{-3}$ of a step fails in every tested cell of $(\partial T/\partial S)_P$, while random departures of $10^{-5}$ of a step give no failing cell. Tables that Zalmoxis writes have regular axes. A missing value (NaN) leaves its cells untested; a stored 0 or inf is a value. Where all values an identity reads are present but its residual is not finite, the cell fails, so a column that is 0 or inf everywhere makes every identity that reads it fail; an identity is skipped only when no cell holds all values it reads, and the check raises when every identity is skipped or a table is missing. On a grid linear in $P$ the $(\partial T/\partial P)_S$ identity finds a $10^{-6}$ temperature fault only where $P$ is large against the step. |

For the file format expected by `EntropyEOS`, see [Reference: data](../data.md).
