# Aragog Data

## `test/` directory

Test lookup tables used by the Aragog test suite. These are minimal datasets for unit and integration testing, not for production simulations.

| File | Description | Format |
|------|-------------|--------|
| `solidus_1d_lookup.dat` | Solidus temperature vs pressure | 2-column text: `# pressure temperature` |
| `liquidus_1d_lookup.dat` | Liquidus temperature vs pressure | 2-column text: `# pressure temperature` |
| `density_2d_lookup.dat` | Density as function of pressure and temperature | 3-column text: `# pressure temperature density` |
| `eos_test.dat` | User-defined EOS profile (radius, pressure, density, gravity) | 4-column text |

The solidus and liquidus curves are derived from the smooth parameterizations in Hamano et al. (2013) for the upper mantle and Andrault et al. (2011) for the lower mantle. See Bower et al. (2018) for details.

## Production EOS data

Production equation-of-state tables (PALEOS, Wolf & Bower 2018, melting curves) are NOT shipped with the Aragog package. They are downloaded at runtime via the PROTEUS data management system (`fwl-io`) or generated by the Zalmoxis interior structure solver.

Key data sources:
- **PALEOS** (Sokolova et al. 2022; Wolf & Bower 2018): MgSiO3 thermodynamic tables in pressure-temperature and pressure-entropy formats. Available from Zenodo.
- **PALEOS-2phase** (Zenodo 18924171): Phase-specific (solid/liquid) tables that avoid interpolation artifacts at the melting curve.
- **Melting curves**: Generated by Zalmoxis from the PALEOS EOS with configurable mushy-zone width factor.

When used within PROTEUS, the Aragog wrapper generates the required P-T lookup tables from PALEOS data and stores them in the simulation output directory.
